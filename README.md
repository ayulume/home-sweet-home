## Installer
You can install Home Sweet Home by running the install script
`python install.py`
Please note it will only work on Arch Linux/Arch-based distros

## Programs used

Wayland Compositor: Niri

Terminal Emulator: Kitty

Launcher: Vicinae

Panel: Waybar

Wallpaper Manager: SwayBG

Shell: ZSH

Cursor: Bibata Modern Classic

Text Editor: Neovim

Notification daemon: Mako

File Explorer: Nautilus

xdg-desktop-portal-gnome
